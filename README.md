# Code Execution Engine

A secure multi-language code execution engine built in Go.

## Overview

This project executes user-submitted code in isolated environments while enforcing security and resource constraints.

Planned features include:
- Python, C++, and JavaScript execution
- Docker-based sandboxing
- CPU and memory limits
- Timeout enforcement
- Concurrent job processing
- REST API interface

## Tech Stack

- Go
- Docker
- REST APIs
- Git & GitHub
